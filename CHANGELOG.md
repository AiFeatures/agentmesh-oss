# Changelog

All notable changes to this project are documented in this file.

## 0.1.0 - 2026-02-18

Initial OSS release with core multi-agent coordination components:

- Added `@agentmesh/hub` with REST + WebSocket coordination APIs
- Added `@agentmesh/cli` for workspace and runtime operations
- Added `@agentmesh/sdk` for TypeScript client integration
- Added `@agentmesh/adapter-interface` for custom adapter implementations
- Added hub-only Docker deployment assets
- Added architecture, protocol, API, events, adapter, and security docs
